Cómo actualizar la web cada jornada

  1. Mete los goles reales en la hoja Resultados del MAESTRO y guarda el Excel.
  2. Sube ese Excel aquí arriba (arrastra o haz clic).
  3. Descarga resultados.json y pronosticos.json.
  4. Ve a tu repositorio en GitHub → sube esos dos archivos (sobrescribiendo) → Commit changes.
  5. En 30 segundos la web recalcula todos los puntos sola.
